Place the DAX web fonts here (public assets).

Expected filenames (update paths in `dax_overrides.css` if you change these):

- Inter-Variable.woff2  (recommended)
- Inter-Regular.woff
- Manrope-Variable.woff2
- Manrope-Regular.woff
- JetBrainsMono-Variable.woff2
- JetBrainsMono-Regular.woff

After adding the files, run the usual build/asset commands for Frappe so
`/assets/dax_branding/fonts/` is up to date.
